## 一、向量代数

### 1. 向量的基本概念

设向量 $a=(a_1,a_2,a_3)$，点 $A(x_1,y_1,z_1)$、点 $B(x_2,y_2,z_2)$。

| 考点 | 必背公式 / 结论 |
| :--- | :--- |
| 【必背】向量模长 | $\vert a\vert=\sqrt{a_1^2+a_2^2+a_3^2}$ |
| 【必背】两点间距离 | $\vert AB\vert=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2+(z_2-z_1)^2}$ |
| 【必背】单位向量 | $e=\dfrac{a}{\vert a\vert}$，要求 $a\neq 0$ |
| 【必背】方向余弦 | $\cos\alpha=\dfrac{a_1}{\vert a\vert},\ \cos\beta=\dfrac{a_2}{\vert a\vert},\ \cos\gamma=\dfrac{a_3}{\vert a\vert}$ |
| 【必背】方向余弦关系 | $\cos^2\alpha+\cos^2\beta+\cos^2\gamma=1$ |

$$\overrightarrow{AB}=(x_2-x_1,\ y_2-y_1,\ z_2-z_1)$$

> 【易错】$\overrightarrow{AB}=B-A$，不要把坐标相减的顺序写反。

### 2. 数量积（点积）

$$a\cdot b=a_1b_1+a_2b_2+a_3b_3=\vert a\vert\vert b\vert\cos\theta$$

| 考点 | 判定方法 |
| :--- | :--- |
| 【必背】垂直 | $a\cdot b=0$，且两向量非零 |
| 【高频】求夹角 | $\cos\theta=\dfrac{a\cdot b}{\vert a\vert\vert b\vert}$ |
| 【高频】求投影 | $a$ 在 $b$ 上的数量投影为 $\dfrac{a\cdot b}{\vert b\vert}$ |
| 【易错】夹角范围 | 向量夹角通常取 $0\le\theta\le\pi$；点积小于零时夹角为钝角 |

**高频题型**：已知两个向量，求夹角、判断是否垂直、求未知参数。

### 3. 向量积（叉积）

$$a\times b=\begin{vmatrix}i & j & k\\ a_1 & a_2 & a_3\\ b_1 & b_2 & b_3\end{vmatrix}$$

| 考点 | 必背结论 |
| :--- | :--- |
| 【必背】叉积模长 | $\vert a\times b\vert=\vert a\vert\vert b\vert\sin\theta$ |
| 【必背】平行判定 | $a\times b=0$，两向量线性相关 |
| 【必背】几何意义 | 平行四边形面积 $S=\vert a\times b\vert$ |
| 【高频】三角形面积 | $S=\dfrac{1}{2}\vert a\times b\vert$ |
| 【易错】运算顺序 | $a\times b=-(b\times a)$ |

> 记忆：**点积求角度；叉积判平行、求面积。**

### 4. 混合积

$$[a,b,c]=a\cdot(b\times c)$$

| 考点 | 必背结论 |
| :--- | :--- |
| 【必背】混合积 | 三阶行列式 |
| 【必背】三向量共面 | $[a,b,c]=0$ |
| 【必背】平行六面体体积 | $V=\vert[a,b,c]\vert$ |
| 【高频】四面体体积 | $V=\dfrac{1}{6}\vert[a,b,c]\vert$ |

## 二、平面方程

### 1. 平面方程的四种常见形式

| 形式 | 必背公式 |
| :--- | :--- |
| 【必背】一般式 | $Ax+By+Cz+D=0$ |
| 【必背】点法式 | $A(x-x_0)+B(y-y_0)+C(z-z_0)=0$ |
| 【高频】截距式 | $\dfrac{x}{a}+\dfrac{y}{b}+\dfrac{z}{c}=1$ |
| 【高频】过三点 | 将三个不共线点代入一般式，求 $A,B,C,D$ 的比例 |

**关键对应关系**：平面 $Ax+By+Cz+D=0$ 的法向量为

$$n=(A,B,C)$$

> 【易错】法向量是平面方程中 $x,y,z$ 的系数，**不包含常数项 $D$**。

### 2. 平面的位置关系

设两平面法向量分别为 $n_1,\ n_2$。

| 关系 | 判定方法 |
| :--- | :--- |
| 【必背】平面平行或重合 | $n_1\times n_2=0$ |
| 【必背】平面垂直 | $n_1\cdot n_2=0$ |
| 【高频】判断重合 | 法向量平行，且两个平面方程的系数（包含常数项）成比例 |
| 【高频】求交线方向 | $s=n_1\times n_2$，两法向量不平行时适用 |
| 【易错】 | 法向量平行只能说明两平面平行或重合，不能直接判定重合 |

### 3. 点到平面的距离

点 $M(x_0,y_0,z_0)$，平面 $Ax+By+Cz+D=0$。

$$d=\frac{\vert Ax_0+By_0+Cz_0+D\vert}{\sqrt{A^2+B^2+C^2}}$$

【高频】求点到平面的距离、求参数使距离等于指定值。

> 【易错】分子必须取绝对值；分母不能漏掉平方根。

## 三、空间直线方程

### 1. 直线的常见形式

直线过点 $M_0(x_0,y_0,z_0)$，方向向量为 $s=(l,m,n)$。

| 形式 | 必背公式 |
| :--- | :--- |
| 【必背】参数式 | $x=x_0+lt,\ y=y_0+mt,\ z=z_0+nt$ |
| 【必背】对称式 | $\dfrac{x-x_0}{l}=\dfrac{y-y_0}{m}=\dfrac{z-z_0}{n}$ |
| 【高频】两点确定直线 | 方向向量 $s=\overrightarrow{AB}$ |
| 【高频】两平面交线 | 两个平面方程联立；方向向量为两平面法向量的叉积 |

> 【易错】方向向量的某个分量为 $0$ 时，对称式不能直接除以该分量，应改用参数式或单独写出对应坐标条件。

### 2. 直线与直线的位置关系

设两直线方向向量为 $s_1,\ s_2$。

| 关系 | 判定方法 |
| :--- | :--- |
| 【必背】平行或重合 | $s_1\times s_2=0$ |
| 【必背】方向垂直 | $s_1\cdot s_2=0$ |
| 【高频】相交 | 联立直线方程，能求出共同点 |
| 【高频】重合 | 方向平行，且两直线有公共点 |
| 【高频】异面直线 | 两直线不平行、不相交 |
| 【高频】异面判定 | $\overrightarrow{M_1M_2}\cdot(s_1\times s_2)\neq 0$ |

> 【易错】空间中两条直线方向垂直，不一定代表两直线相交；异面直线也可能具有垂直的方向向量。

## 四、直线与平面的位置关系

设直线方向向量为 $s=(l,m,n)$，平面法向量为 $n=(A,B,C)$。

| 关系 | 判定方法 |
| :--- | :--- |
| 【必背】直线平行于平面或在平面内 | $s\cdot n=0$ |
| 【必背】直线垂直于平面 | $s\parallel n$ |
| 【高频】直线在平面内 | 方向垂直于法向量，且直线上一点满足平面方程 |
| 【高频】直线与平面相交 | $s\cdot n\neq 0$ |
| 【高频】求交点 | 把直线参数式代入平面方程，先求参数，再求坐标 |

### 直线与平面的夹角

$$\sin\theta=\frac{\vert s\cdot n\vert}{\vert s\vert\vert n\vert}$$

其中 $\theta$ 是直线与平面的夹角，范围为 $0\le\theta\le\dfrac{\pi}{2}$。

> 【易错】这里用 $\sin$，不是 $\cos$；直线与平面的夹角，等于直线方向向量与平面法向量夹角的余角。

## 五、夹角与距离综合公式

### 1. 角度公式

| 对象 | 必背公式 |
| :--- | :--- |
| 两向量夹角 | $\cos\theta=\dfrac{a\cdot b}{\vert a\vert\vert b\vert}$ |
| 两直线夹角 | $\cos\theta=\dfrac{\vert s_1\cdot s_2\vert}{\vert s_1\vert\vert s_2\vert}$ |
| 两平面夹角 | $\cos\theta=\dfrac{\vert n_1\cdot n_2\vert}{\vert n_1\vert\vert n_2\vert}$ |
| 直线与平面夹角 | $\sin\theta=\dfrac{\vert s\cdot n\vert}{\vert s\vert\vert n\vert}$ |

### 2. 距离公式

| 对象 | 必背公式 |
| :--- | :--- |
| 点到平面 | $d=\dfrac{\vert Ax_0+By_0+Cz_0+D\vert}{\sqrt{A^2+B^2+C^2}}$ |
| 点到直线 | $d=\dfrac{\vert\overrightarrow{M_0M}\times s\vert}{\vert s\vert}$ |
| 两条平行直线 | 取一条直线上的点，求其到另一条直线的距离 |
| 两异面直线 | $d=\dfrac{\vert\overrightarrow{M_1M_2}\cdot(s_1\times s_2)\vert}{\vert s_1\times s_2\vert}$ |

## 六、球面方程（大纲涉及时必看）

| 考点 | 必背公式 / 结论 |
| :--- | :--- |
| 【必背】球心、半径已知 | $(x-a)^2+(y-b)^2+(z-c)^2=R^2$ |
| 【高频】一般式 | $x^2+y^2+z^2+Ax+By+Cz+D=0$ |
| 【必背】球心 | $\left(-\dfrac{A}{2},\ -\dfrac{B}{2},\ -\dfrac{C}{2}\right)$ |
| 【必背】半径 | $R=\sqrt{\dfrac{A^2+B^2+C^2}{4}-D}$ |

> 【易错】一般式要先确认半径平方非负，才能表示实球面。

## 七、专升本高频题型归纳

| 题型 | 解题抓手 |
| :--- | :--- |
| 【高频】求向量夹角 | 点积公式 |
| 【高频】判断向量平行或垂直 | 平行看叉积，垂直看点积 |
| 【高频】求三角形面积、四面体体积 | 叉积模长、混合积绝对值 |
| 【高频】求平面方程 | 找法向量，再代入已知点 |
| 【高频】求直线方程 | 找直线上一点和方向向量 |
| 【高频】判定空间位置关系 | 先比较方向向量、法向量，再检查公共点 |
| 【高频】求直线与平面交点 | 参数式代入平面方程 |
| 【高频】求距离 | 先辨认距离对象，再套对应公式 |
| 【高频】含参数的平行、垂直问题 | 代入点积为 $0$、叉积为 $0$ 等条件求参数 |

## 八、易错点集中记忆

- **点积和叉积不要混用**：点积是数，叉积是向量。
- **平行不等于重合**：必须进一步检查公共点或方程比例。
- **直线垂直于平面**：直线方向向量平行于平面法向量。
- **直线与平面夹角**：用正弦公式；线与线、面与面通常用余弦公式。
- **距离公式**：分子常需要绝对值，分母不能漏。
- **求直线方程**：一个点加一个方向向量；求平面方程：一个点加一个法向量。
- **参数式比对称式更稳妥**：方向向量存在零分量时优先考虑参数式。
