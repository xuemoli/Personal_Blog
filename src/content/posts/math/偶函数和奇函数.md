# 奇函数与偶函数 知识点整理

---

## 一、基本定义
> **前提条件**：函数的定义域必须**关于原点对称**。即对任意 $x \in D$，都有 $-x \in D$。定义域不对称的函数，一定是非奇非偶函数。

### 1. 偶函数
若对定义域内的任意 $x$，都满足：
$$\boldsymbol{f(-x) = f(x)}$$
则称 $f(x)$ 为**偶函数**。

- **图像特征**：函数图像关于 **$y$ 轴** 轴对称
- **示例**：$f(x)=x^2$、$f(x)=\cos x$

### 2. 奇函数
若对定义域内的任意 $x$，都满足：
$$\boldsymbol{f(-x) = -f(x)}$$
则称 $f(x)$ 为**奇函数**。

- **图像特征**：函数图像关于 **坐标原点** 中心对称
- **重要性质**：若奇函数在 $x=0$ 处有定义，则必有 $\boldsymbol{f(0)=0}$
- **示例**：$f(x)=x^3$、$f(x)=\sin x$

---

## 二、判别方法与标准步骤
1. **第一步：校验定义域**
   先判断函数定义域是否关于原点对称。
   - 不对称 → 直接判定为**非奇非偶函数**，无需后续计算
   - 对称 → 进入下一步判断

2. **第二步：计算 $f(-x)$**
   将表达式中所有的 $x$ 替换为 $-x$，化简得到 $f(-x)$ 的最简形式。

3. **第三步：对比判定**
   - 若 $f(-x) = f(x)$ → **偶函数**
   - 若 $f(-x) = -f(x)$ → **奇函数**
   - 两者都不满足 → **非奇非偶函数**

---

## 三、运算性质速查表
设 $f(x)$、$g(x)$ 定义域均关于原点对称：

| 运算类型 | 结果奇偶性 |
| :--- | :--- |
| 奇函数 $\pm$ 奇函数 | 奇函数 |
| 偶函数 $\pm$ 偶函数 | 偶函数 |
| 奇函数 $\times$ 奇函数 | 偶函数 |
| 偶函数 $\times$ 偶函数 | 偶函数 |
| 奇函数 $\times$ 偶函数 | 奇函数 |

> 速记口诀：同乘得偶，异乘得奇；同加同性，异加不定。

---

## 四、常见函数奇偶性速记

| 函数类型 | 函数表达式 | 奇偶性 |
| :--- | :--- | :--- |
| 幂函数 | $x^n$ | $n$ 为偶数 → 偶；$n$ 为奇数 → 奇 |
| 三角函数 | $\sin x$ | 奇函数 |
| 三角函数 | $\cos x$ | 偶函数 |
| 三角函数 | $\tan x$ | 奇函数 |
| 常函数 | $f(x)=C\ (C\neq0)$ | 偶函数 |
| 常函数 | $f(x)=0$ | 既是奇函数也是偶函数 |

## 五、对称区间积分结论（高数高频考点）
在对称区间 $[-a,\,a]$ 上：

> ✅ **奇函数积分**
> $$\int_{-a}^{a} f(x)\,\mathrm{d}x = 0$$
> 奇函数在对称区间上的定积分为0。

> ✅ **偶函数积分**
> $$\int_{-a}^{a} f(x)\,\mathrm{d}x = 2\int_{0}^{a} f(x)\,\mathrm{d}x$$
> 偶函数在对称区间上的定积分，等于半区间积分的2倍。
