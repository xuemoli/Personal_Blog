# 定积分中的奇偶性判断：对称区间上的积分技巧

## 一、核心结论

设函数 $f(x)$ 在关于原点对称的区间 $[-a, a]$（$a>0$）上连续，则有：

| 函数的奇偶性 | 积分结论 |
|---|---|
| $f(x)$ 为**奇函数**，即 $f(-x) = -f(x)$ | $\displaystyle\int_{-a}^{a} f(x)\,\mathrm{d}x = 0$ |
| $f(x)$ 为**偶函数**，即 $f(-x) = f(x)$ | $\displaystyle\int_{-a}^{a} f(x)\,\mathrm{d}x = 2\int_{0}^{a} f(x)\,\mathrm{d}x$ |

> **一句话记忆**：对称区间上，**奇函数积分为零，偶函数积分翻倍**。

## 二、结论的证明

利用定积分的区间可加性，将积分拆成两部分：

$$\int_{-a}^{a} f(x)\,\mathrm{d}x = \int_{-a}^{0} f(x)\,\mathrm{d}x + \int_{0}^{a} f(x)\,\mathrm{d}x$$

对第一个积分作换元 $x = -t$，则 $\mathrm{d}x = -\mathrm{d}t$，当 $x=-a$ 时 $t=a$，当 $x=0$ 时 $t=0$：

$$\int_{-a}^{0} f(x)\,\mathrm{d}x = \int_{a}^{0} f(-t)(-\mathrm{d}t) = \int_{0}^{a} f(-t)\,\mathrm{d}t = \int_{0}^{a} f(-x)\,\mathrm{d}x$$

于是：

$$\int_{-a}^{a} f(x)\,\mathrm{d}x = \int_{0}^{a} \big[f(x) + f(-x)\big]\,\mathrm{d}x$$

- 若 $f$ 为奇函数，$f(-x) = -f(x)$，则被积函数 $f(x)+f(-x) = 0$，积分为 $0$；
- 若 $f$ 为偶函数，$f(-x) = f(x)$，则被积函数 $f(x)+f(-x) = 2f(x)$，积分翻倍。

证明完毕。$\blacksquare$

## 三、一个更一般的公式（重要！）

由上面的证明过程直接得到一个对**任意函数**都成立的万能公式：

$$\boxed{\int_{-a}^{a} f(x)\,\mathrm{d}x = \int_{0}^{a} \big[f(x) + f(-x)\big]\,\mathrm{d}x}$$

**含义**：即使 $f(x)$ 本身既不是奇函数也不是偶函数，只要积分区间对称，就可以用这个公式把"负半轴"的信息转移到"正半轴"上。奇偶性只是这个公式的特例。

**推论（偶部/奇部分解）**：任意函数都可以唯一分解为偶部与奇部之和：

$$f(x) = \underbrace{\frac{f(x)+f(-x)}{2}}_{\text{偶函数}} + \underbrace{\frac{f(x)-f(-x)}{2}}_{\text{奇函数}}$$

对称区间积分时奇部自动消失，故：

$$\int_{-a}^{a} f(x)\,\mathrm{d}x = 2\int_{0}^{a} \frac{f(x)+f(-x)}{2}\,\mathrm{d}x = \int_{0}^{a}\big[f(x)+f(-x)\big]\,\mathrm{d}x$$

与上面公式一致。

## 四、如何判断被积函数的奇偶性

### 4.1 奇偶性的判定法则

设 $f, g$ 定义域关于原点对称，则：

| 运算 | 结论 |
|---|---|
| 奇 ± 奇 | 奇函数 |
| 偶 ± 偶 | 偶函数 |
| 奇 × 奇 或 偶 × 偶 | 偶函数 |
| 奇 × 偶 | 奇函数 |
| 复合 $f(g(x))$ | 内层偶 ⇒ 整体偶；内层奇且外层奇 ⇒ 整体奇 |
| 求导 $f'(x)$ | 偶函数的导数是奇函数；奇函数的导数是偶函数 |
| 变上限积分 $\int_0^x f(t)\,\mathrm{d}t$ | 奇函数的原函数（过原点）是偶函数；偶函数的原函数一般是奇函数加常数 |

### 4.2 常用基本函数的奇偶性

- **奇函数**：$x^n$（$n$ 为奇数）、$\sin x$、$\tan x$、$\arcsin x$、$\arctan x$、$\dfrac{a^x - a^{-x}}{2}$（双曲正弦 $\sinh x$）
- **偶函数**：$x^n$（$n$ 为偶数）、$\cos x$、$|x|$、常数函数、$\dfrac{a^x + a^{-x}}{2}$（双曲余弦 $\cosh x$）
- **非奇非偶**：$e^x$、$\ln(1+x)$、$x^2 + x$ 等（但它们在对称区间上仍可用万能公式）

## 五、典型例题

### 例 1（直接应用奇偶性）

计算 $\displaystyle\int_{-1}^{1} \left(x^3 \cos x + \frac{1}{1+x^2}\right)\mathrm{d}x$。

**分析**：

- $x^3$ 是奇函数，$\cos x$ 是偶函数，奇 × 偶 = 奇，故 $x^3\cos x$ 为奇函数，其在对称区间上积分为 $0$；
- $\dfrac{1}{1+x^2}$ 是偶函数，积分翻倍。

**解**：

$$\int_{-1}^{1} \left(x^3 \cos x + \frac{1}{1+x^2}\right)\mathrm{d}x = 0 + 2\int_{0}^{1}\frac{\mathrm{d}x}{1+x^2} = 2\arctan x \Big|_0^1 = 2 \times \frac{\pi}{4} = \frac{\pi}{2}$$

### 例 2（被积函数非奇非偶，用万能公式）

计算 $\displaystyle\int_{-1}^{1} \frac{x^2}{1 + e^x}\,\mathrm{d}x$。

**分析**：$f(x) = \dfrac{x^2}{1+e^x}$ 既非奇函数也非偶函数，但区间 $[-1,1]$ 对称，使用万能公式：

**解**：

$$f(x) + f(-x) = \frac{x^2}{1+e^x} + \frac{x^2}{1+e^{-x}} = x^2\left(\frac{1}{1+e^x} + \frac{e^x}{1+e^x}\right) = x^2$$

因此：

$$\int_{-1}^{1} \frac{x^2}{1+e^x}\,\mathrm{d}x = \int_{0}^{1} x^2\,\mathrm{d}x = \frac{1}{3}$$

> 本题是考研中的经典题。若想不到奇偶性技巧而硬算原函数，将极其繁琐。

### 例 3（拆分后分别判断）

计算 $\displaystyle\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}} \left(x^2 + x\right)\cos x\,\mathrm{d}x$。

**分析**：拆成两部分分别判断：

- $x^2\cos x$：偶 × 偶 = 偶；
- $x\cos x$：奇 × 偶 = 奇，积分为 $0$。

**解**：

$$\text{原式} = 2\int_{0}^{\frac{\pi}{2}} x^2 \cos x\,\mathrm{d}x$$

对剩余部分用分部积分：

$$\int x^2\cos x\,\mathrm{d}x = x^2\sin x + 2x\cos x - 2\sin x + C$$

代入上下限：

$$2\left[x^2\sin x + 2x\cos x - 2\sin x\right]_0^{\frac{\pi}{2}} = 2\left(\frac{\pi^2}{4} - 2\right) = \frac{\pi^2}{2} - 4$$

### 例 4（区间不对称时先改造）

计算 $\displaystyle\int_{-1}^{2} x\sqrt{|x|}\,\mathrm{d}x$ 的思路提示。

**分析**：区间 $[-1,2]$ 不对称，不能直接套公式。处理方法是拆区间：

$$\int_{-1}^{2} = \int_{-1}^{1} + \int_{1}^{2}$$

第一部分中 $x\sqrt{|x|}$ 是奇函数（$x$ 奇，$\sqrt{|x|}$ 偶，奇 × 偶 = 奇），积分为 $0$，只需计算：

$$\int_{1}^{2} x\sqrt{x}\,\mathrm{d}x = \int_{1}^{2} x^{\frac{3}{2}}\,\mathrm{d}x = \frac{2}{5}x^{\frac{5}{2}}\Big|_1^2 = \frac{2}{5}\left(4\sqrt{2} - 1\right)$$

## 六、常见易错点与注意事项

1. **区间必须关于原点对称** ⚠️
   这是奇偶性技巧成立的前提。区间 $[0, a]$、$[1, 2]$、$[-1, 3]$ 等都不能直接使用，必须先拆区间改造。

2. **先检查被积函数的连续性**
   若 $f$ 在 $[-a,a]$ 内有瑕点（如 $\int_{-1}^{1}\frac{\mathrm{d}x}{x^2}$），需要先讨论反常积分的敛散性，不能直接套奇偶性结论。特别注意：$\dfrac{1}{x}$ 在 $[-1,1]$ 上是奇函数，但其积分**发散**，并不等于 $0$！

3. **复合函数要从内向外判断**
   例如 $\sin(x^2)$：内层 $x^2$ 是偶函数，所以整体是偶函数；而 $\sin^2 x$：内层 $\sin x$ 是奇函数、外层平方是偶函数，"内奇外偶 ⇒ 偶"，结果也是偶函数——判断路径不同，结论都正确。

4. **不要漏掉常数因子**
   偶函数积分是**两倍**而不是保持不变，写答案时容易丢系数 2。

5. **加法拆分后逐项判断**
   奇 + 偶 = 非奇非偶，此时把被积函数拆成"奇的部分 + 偶的部分"，奇的部分积分为零，只算偶的部分。

## 七、与其他对称性技巧的对比（进阶）

| 技巧 | 适用条件 | 核心公式 |
|---|---|---|
| 奇偶性 | 区间 $[-a,a]$，$f$ 有奇偶性 | 奇积分为 0，偶翻倍 |
| 万能公式 | 区间 $[-a,a]$，$f$ 任意 | $\int_{-a}^a f = \int_0^a [f(x)+f(-x)]\,\mathrm{d}x$ |
| 周期函数 | $f$ 以 $T$ 为周期 | $\int_a^{a+T} f = \int_0^T f$，与起点无关 |
| 区间再现 | $f$ 在 $[0, a]$ 连续 | $\int_0^a f(x)\,\mathrm{d}x = \int_0^a f(a-x)\,\mathrm{d}x$（常用于三角函数的配对） |
| 华里士公式 | $[0, \frac{\pi}{2}]$ 上 $\sin^n, \cos^n$ | $\int_0^{\frac{\pi}{2}}\sin^n x\,\mathrm{d}x = \int_0^{\frac{\pi}{2}}\cos^n x\,\mathrm{d}x$，按 $n$ 奇偶递推 |

## 八、总结

- **判断流程**：一看**区间**是否对称 → 二看**被积函数**的奇偶性（必要时拆项或用万能公式）→ 三套用结论化简。
- 奇偶性技巧能把复杂的对称区间积分化简为零或一半区间上的积分，再配合换元、分部积分等方法，往往能把"算不出原函数"的题变成简单题。
- 记住三个关键词：**对称区间**、**奇零偶倍**、**万能公式** $f(x)+f(-x)$。
