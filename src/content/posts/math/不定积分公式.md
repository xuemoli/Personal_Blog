## 一、基本积分公式

| 公式 | 说明 |
|------|------|
| $\displaystyle\int 0\,\mathrm{d}x = C$ | 常数积分 |
| $\displaystyle\int x^u\,\mathrm{d}x = \frac{x^{u+1}}{u+1} + C\;(u \neq -1)$ | 幂函数积分 |
| $\displaystyle\int \frac{1}{x}\,\mathrm{d}x = \ln\|x\| + C$ | 倒数积分 |
| $\displaystyle\int a^x\,\mathrm{d}x = \frac{a^x}{\ln a} + C$ | 指数函数积分 |
| $\displaystyle\int e^x\,\mathrm{d}x = e^x + C$ | 自然指数积分 |
| $\displaystyle\int \sin x\,\mathrm{d}x = -\cos x + C$ | 正弦积分 |
| $\displaystyle\int \cos x\,\mathrm{d}x = \sin x + C$ | 余弦积分 |
| $\displaystyle\int \frac{1}{\cos^2 x}\mathrm{d}x = \tan x + C$ | 正割平方积分 |
| $\displaystyle\int \frac{1}{\sin^2 x}\mathrm{d}x = -\cot x + C$ | 余割平方积分 |
| $\displaystyle\int \frac{1}{\sqrt{1-x^2}}\mathrm{d}x = \arcsin x + C$ | 反正弦积分 |
| $\displaystyle\int \frac{1}{1+x^2}\mathrm{d}x = \arctan x + C$ | 反正切积分 |
| $\displaystyle\int \frac{1}{a^2-x^2}\mathrm{d}x = \frac{1}{2a}\ln\left\|\frac{a+x}{a-x}\right\| + C$ | 分式积分 |
| $\displaystyle\int \sec x\,\mathrm{d}x = \ln\|\sec x + \tan x\| + C$ | 正割积分 |
| $\displaystyle\int \frac{1}{a^2+x^2}\mathrm{d}x = \frac{1}{a}\arctan\frac{x}{a} + C$ | 分式反正切 |
| $\displaystyle\int \frac{1}{\sqrt{a^2-x^2}}\mathrm{d}x = \arcsin\frac{x}{a} + C$ | 带参数反正弦 |
| $\displaystyle\int \sec^2 x\,\mathrm{d}x = \tan x + C$ | 正割平方 |
| $\displaystyle\int \operatorname{sh} x\,\mathrm{d}x = \operatorname{ch} x + C$ | 双曲正弦积分 |
| $\displaystyle\int \operatorname{ch} x\,\mathrm{d}x = \operatorname{sh} x + C$ | 双曲余弦积分 |
| $\displaystyle\int \operatorname{th} x\,\mathrm{d}x = \ln(\operatorname{ch} x) + C$ | 双曲正切积分 |

> 补充两个由换元法导出、但应当直接记住的公式：
>
> $$
> \int \frac{\mathrm{d}x}{\sqrt{x^2+a^2}} = \ln\left(x + \sqrt{x^2+a^2}\right) + C
> $$
>
> $$
> \int \frac{\mathrm{d}x}{\sqrt{x^2-a^2}} = \ln\left|x + \sqrt{x^2-a^2}\right| + C \quad (|x| > a)
> $$

## 二、核心概念

**不定积分**是求导的逆运算：若 $F'(x)=f(x)$，则

$$
\int f(x)\,\mathrm{d}x = F(x) + C
$$

其中 $F(x)$ 称为 $f(x)$ 的一个**原函数**，$C$ 为任意常数。连续函数一定存在原函数（原函数存在定理）。

不定积分有两条常用性质：

| 性质 | 公式 |
|------|------|
| 线性性质 | $\displaystyle\int [\alpha f(x) + \beta g(x)]\,\mathrm{d}x = \alpha\int f(x)\,\mathrm{d}x + \beta\int g(x)\,\mathrm{d}x$ |
| 微分与积分互逆 | $\displaystyle\left(\int f(x)\,\mathrm{d}x\right)' = f(x)$，$\displaystyle\int F'(x)\,\mathrm{d}x = F(x) + C$ |

> **注意**：不定积分的结果**必须带任意常数 $C$**，漏掉 $C$ 是最常见的失分点。

## 三、第一类换元积分法（凑微分法）

### 3.1 原理

设 $f(u)$ 有原函数 $F(u)$，$u = \varphi(x)$ 可导，由复合函数求导法则的逆用：

$$
\int f[\varphi(x)]\,\varphi'(x)\,\mathrm{d}x = \int f[\varphi(x)]\,\mathrm{d}\varphi(x) = F[\varphi(x)] + C
$$

即把 $\varphi'(x)\,\mathrm{d}x$ **凑**成 $\mathrm{d}\varphi(x)$，从而把被积表达式整体看作关于 $u$ 的积分。

**关键点**：$u$ 由自己选取（"凑"），所以第一类换元法不需要回代，也**不要求 $\varphi$ 单调**。

### 3.2 常用凑微分形式

| 凑微分 | 说明 |
|------|------|
| $\mathrm{d}x = \frac{1}{a}\,\mathrm{d}(ax+b)$ | 线性代换 |
| $x\,\mathrm{d}x = \frac{1}{2}\,\mathrm{d}(x^2)$ | 幂函数配凑 |
| $x^{n}\,\mathrm{d}x = \frac{1}{n+1}\,\mathrm{d}(x^{n+1})$ | 幂函数配凑 |
| $\frac{\mathrm{d}x}{x} = \mathrm{d}(\ln\|x\|)$ | 对数配凑 |
| $\frac{\mathrm{d}x}{\sqrt{x}} = 2\,\mathrm{d}(\sqrt{x})$ | 根式配凑 |
| $e^{x}\,\mathrm{d}x = \mathrm{d}(e^{x})$ | 指数配凑 |
| $a^{x}\,\mathrm{d}x = \frac{1}{\ln a}\,\mathrm{d}(a^{x})$ | 指数配凑 |
| $\sin x\,\mathrm{d}x = -\mathrm{d}(\cos x)$ | 三角配凑 |
| $\cos x\,\mathrm{d}x = \mathrm{d}(\sin x)$ | 三角配凑 |
| $\frac{\mathrm{d}x}{\cos^2 x} = \mathrm{d}(\tan x)$ | 三角配凑 |
| $\frac{\mathrm{d}x}{\sin^2 x} = -\mathrm{d}(\cot x)$ | 三角配凑 |
| $\frac{\mathrm{d}x}{1+x^2} = \mathrm{d}(\arctan x)$ | 反三角配凑 |
| $\frac{\mathrm{d}x}{\sqrt{1-x^2}} = \mathrm{d}(\arcsin x)$ | 反三角配凑 |

### 3.3 典型例题

**例 1** 计算 $\displaystyle\int x e^{x^2}\,\mathrm{d}x$。

**解**：注意到 $x\,\mathrm{d}x = \frac{1}{2}\mathrm{d}(x^2)$，令 $u = x^2$：

$$
\int x e^{x^2}\,\mathrm{d}x = \frac{1}{2}\int e^{x^2}\,\mathrm{d}(x^2) = \frac{1}{2}e^{x^2} + C
$$

**例 2** 计算 $\displaystyle\int \frac{\mathrm{d}x}{x\ln x}$。

**解**：注意到 $\frac{\mathrm{d}x}{x} = \mathrm{d}(\ln x)$，令 $u = \ln x$：

$$
\int \frac{\mathrm{d}x}{x\ln x} = \int \frac{\mathrm{d}(\ln x)}{\ln x} = \ln\left|\ln x\right| + C
$$

**例 3** 计算 $\displaystyle\int \frac{\mathrm{d}x}{a^2+x^2}\;(a > 0)$。

**解**：提取 $a^2$ 后凑微分：

$$
\int \frac{\mathrm{d}x}{a^2+x^2} = \frac{1}{a^2}\int \frac{\mathrm{d}x}{1+\left(\frac{x}{a}\right)^2} = \frac{1}{a}\int \frac{\mathrm{d}\left(\frac{x}{a}\right)}{1+\left(\frac{x}{a}\right)^2} = \frac{1}{a}\arctan\frac{x}{a} + C
$$

> 这正是公式表中"分式反正切"的来历——**基本公式表里的参数形式几乎都能用凑微分推出来**。

## 四、第二类换元积分法（变量代换法）

### 4.1 原理

与第一类换元法方向相反：第一类是把 $x$ 的函数凑成新变量 $u$，第二类则是**主动引入新变量 $t$，令 $x = \varphi(t)$**：

$$
\int f(x)\,\mathrm{d}x \;\;\overset{x\,=\,\varphi(t)}{\longrightarrow}\;\; \int f[\varphi(t)]\,\varphi'(t)\,\mathrm{d}t
$$

**成立条件**（与第一类的本质区别）：

- $x = \varphi(t)$ 在区间上**单调、可导**，且 $\varphi'(t) \neq 0$（保证反函数 $t = \varphi^{-1}(x)$ 存在）；
- 求出关于 $t$ 的原函数后，**必须回代** $t = \varphi^{-1}(x)$，把结果换回 $x$。

两类换元法的对比：

| 对比项 | 第一类换元法 | 第二类换元法 |
|------|------|------|
| 代换方向 | $u = \varphi(x)$（凑进去） | $x = \varphi(t)$（换出来） |
| 对 $\varphi$ 的要求 | 只需可导 | 需单调、可导、$\varphi'(t) \neq 0$ |
| 是否需要回代 | 不需要 | **必须回代** |
| 典型场景 | 被积函数中出现"某函数的导数" | 被积函数含**根式**，无法直接凑微分 |

### 4.2 三角代换

凡遇到 $\sqrt{a^2 \pm x^2}$、$\sqrt{x^2 - a^2}$ 形式的根式，用三角代换去掉根号：

| 根式形式 | 代换 | 依据的恒等式 | $t$ 的范围 |
|------|------|------|------|
| $\sqrt{a^2-x^2}$ | $x = a\sin t$ | $1 - \sin^2 t = \cos^2 t$ | $t \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$ |
| $\sqrt{a^2+x^2}$ | $x = a\tan t$ | $1 + \tan^2 t = \sec^2 t$ | $t \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ |
| $\sqrt{x^2-a^2}$ | $x = a\sec t$ | $\sec^2 t - 1 = \tan^2 t$ | $t \in \left[0, \frac{\pi}{2}\right) \cup \left[\frac{\pi}{2}, \pi\right)$ |

**回代技巧：辅助直角三角形**（不必死记反函数表达式）

设斜边与邻边的长度由代换关系确定，第三边用勾股定理算出，则 $\sin t$、$\cos t$、$\tan t$ 直接读图：

| 代换 | 邻边 | 对边 | 斜边 | 由此得到 |
|------|------|------|------|------|
| $x = a\sin t$ | $\sqrt{a^2-x^2}$ | $x$ | $a$ | $\sin t = \frac{x}{a}$，$\cos t = \frac{\sqrt{a^2-x^2}}{a}$ |
| $x = a\tan t$ | $a$ | $x$ | $\sqrt{a^2+x^2}$ | $\tan t = \frac{x}{a}$，$\sec t = \frac{\sqrt{a^2+x^2}}{a}$ |
| $x = a\sec t$ | $a$ | $\sqrt{x^2-a^2}$ | $x$ | $\sec t = \frac{x}{a}$，$\tan t = \frac{\sqrt{x^2-a^2}}{a}$ |

### 4.3 三角代换例题

**例 1** 计算 $\displaystyle\int \sqrt{a^2-x^2}\,\mathrm{d}x\;(a>0)$。

**解**：令 $x = a\sin t$，$\mathrm{d}x = a\cos t\,\mathrm{d}t$，则 $\sqrt{a^2-x^2} = a\cos t$：

$$
\begin{aligned}
\int \sqrt{a^2-x^2}\,\mathrm{d}x &= \int a\cos t \cdot a\cos t\,\mathrm{d}t = a^2\int \cos^2 t\,\mathrm{d}t \\
&= a^2\int \frac{1+\cos 2t}{2}\,\mathrm{d}t = \frac{a^2}{2}\left(t + \frac{\sin 2t}{2}\right) + C \\
&= \frac{a^2}{2}\left(t + \sin t\cos t\right) + C
\end{aligned}
$$

回代：$t = \arcsin\frac{x}{a}$，$\sin t = \frac{x}{a}$，$\cos t = \frac{\sqrt{a^2-x^2}}{a}$，于是

$$
\int \sqrt{a^2-x^2}\,\mathrm{d}x = \frac{a^2}{2}\arcsin\frac{x}{a} + \frac{x}{2}\sqrt{a^2-x^2} + C
$$

**例 2** 计算 $\displaystyle\int \frac{\mathrm{d}x}{\sqrt{x^2+a^2}}\;(a>0)$。

**解**：令 $x = a\tan t$，$\mathrm{d}x = a\sec^2 t\,\mathrm{d}t$，$\sqrt{x^2+a^2} = a\sec t$：

$$
\int \frac{\mathrm{d}x}{\sqrt{x^2+a^2}} = \int \frac{a\sec^2 t}{a\sec t}\,\mathrm{d}t = \int \sec t\,\mathrm{d}t = \ln\left|\sec t + \tan t\right| + C
$$

回代 $\tan t = \frac{x}{a}$，$\sec t = \frac{\sqrt{x^2+a^2}}{a}$：

$$
= \ln\left|\frac{\sqrt{x^2+a^2}}{a} + \frac{x}{a}\right| + C = \ln\left(x + \sqrt{x^2+a^2}\right) + C
$$

（$\ln a$ 是常数，已并入 $C$。）

> 这就是开头补充公式的来源。同类做法可推出 $\displaystyle\int\frac{\mathrm{d}x}{\sqrt{x^2-a^2}} = \ln\left|x+\sqrt{x^2-a^2}\right| + C$（令 $x = a\sec t$）。

### 4.4 根式代换

被积函数含 $\sqrt[n]{ax+b}$ 时，直接令整个根式为 $t$，把根号"整体消掉"：

$$
\sqrt[n]{ax+b} = t \;\Longrightarrow\; x = \frac{t^n - b}{a},\quad \mathrm{d}x = \frac{n}{a}t^{n-1}\,\mathrm{d}t
$$

**例 3** 计算 $\displaystyle\int \frac{\mathrm{d}x}{1+\sqrt{x}}$。

**解**：令 $t = \sqrt{x}$，则 $x = t^2$，$\mathrm{d}x = 2t\,\mathrm{d}t$：

$$
\int \frac{\mathrm{d}x}{1+\sqrt{x}} = \int \frac{2t}{1+t}\,\mathrm{d}t = 2\int \left(1 - \frac{1}{1+t}\right)\mathrm{d}t = 2t - 2\ln\left|1+t\right| + C
$$

回代 $t = \sqrt{x}$：

$$
= 2\sqrt{x} - 2\ln\left(1+\sqrt{x}\right) + C
$$

> 若同时含 $\sqrt{x}$ 与 $\sqrt[3]{x}$，则令 $x = t^6$（取各根指数的最小公倍数），可一次消去所有根号。

### 4.5 倒代换

当分母中 $x$ 的次数明显高于分子时，令 $x = \dfrac{1}{t}$（即倒代换），常能化简。

**例 4** 计算 $\displaystyle\int \frac{\mathrm{d}x}{x^2\sqrt{x^2+1}}\;(x>0)$。

**解**：令 $x = \frac{1}{t}$，则 $\mathrm{d}x = -\frac{\mathrm{d}t}{t^2}$，$\sqrt{x^2+1} = \frac{\sqrt{t^2+1}}{t}$：

$$
\int \frac{\mathrm{d}x}{x^2\sqrt{x^2+1}} = \int \frac{-\frac{\mathrm{d}t}{t^2}}{\frac{1}{t^2}\cdot\frac{\sqrt{t^2+1}}{t}} = -\int \frac{t\,\mathrm{d}t}{\sqrt{t^2+1}} = -\sqrt{t^2+1} + C
$$

回代 $t = \frac{1}{x}$，$\sqrt{t^2+1} = \frac{\sqrt{x^2+1}}{x}$（$x>0$）：

$$
= -\frac{\sqrt{x^2+1}}{x} + C
$$

## 五、分部积分法

### 5.1 公式与推导

由乘积求导法则 $(uv)' = u'v + uv'$ 移项积分，得到分部积分公式：

$$
\boxed{\int u\,\mathrm{d}v = uv - \int v\,\mathrm{d}u}
$$

即 $\displaystyle\int uv'\,\mathrm{d}x = uv - \int u'v\,\mathrm{d}x$。它把"难积的 $\int u\,\mathrm{d}v$"换成"好积的 $\int v\,\mathrm{d}u$"。

### 5.2 $u$ 与 $\mathrm{d}v$ 的选取：反对幂指三

优先把**排在前面**的函数取作 $u$，剩下的连同 $\mathrm{d}x$ 一起取作 $\mathrm{d}v$：

$$
\underbrace{\text{反}}_{\text{反三角}}\;\underbrace{\text{对}}_{\text{对数}}\;\underbrace{\text{幂}}_{\text{幂函数}}\;\underbrace{\text{指}}_{\text{指数}}\;\underbrace{\text{三}}_{\text{三角}}
$$

- 适用于：三角函数 × $x$、指数/对数函数 × $x$ 等乘积形式；
- 若 $u$ 取错方向，$\int v\,\mathrm{d}u$ 会比原积分更复杂，此时应交换 $u$ 与 $\mathrm{d}v$。

### 5.3 典型例题

**例 1** 计算 $\displaystyle\int x e^x\,\mathrm{d}x$。

**解**：取 $u = x$，$\mathrm{d}v = e^x\mathrm{d}x$，则 $\mathrm{d}u = \mathrm{d}x$，$v = e^x$：

$$
\int x e^x\,\mathrm{d}x = x e^x - \int e^x\,\mathrm{d}x = x e^x - e^x + C = e^x(x-1) + C
$$

> **表格法**：对 $\int x^2 e^x\,\mathrm{d}x$ 这类需多次分部积分的题目，可列两列——左列对 $u$ 反复求导到 $0$，右列对 $v$ 反复积分，斜向相乘并交替取正负号：
>
> | 求导列（取 $u$） | 积分列（取 $v$） | 符号 |
> |---|---|---|
> | $x^2$ | $e^x$ | $+$ |
> | $2x$ | $e^x$ | $-$ |
> | $2$ | $e^x$ | $+$ |
> | $0$ | $e^x$ | — |
>
> 故 $\displaystyle\int x^2 e^x\,\mathrm{d}x = x^2 e^x - 2x e^x + 2e^x + C = e^x\left(x^2-2x+2\right) + C$。

**例 2** 计算 $\displaystyle\int \ln x\,\mathrm{d}x$。

**解**：取 $u = \ln x$，$\mathrm{d}v = \mathrm{d}x$，则 $\mathrm{d}u = \frac{\mathrm{d}x}{x}$，$v = x$：

$$
\int \ln x\,\mathrm{d}x = x\ln x - \int x\cdot\frac{\mathrm{d}x}{x} = x\ln x - x + C
$$

> 被积函数只有一项时，也可把 $\mathrm{d}x$ 当作 $\mathrm{d}v$，这是"对数函数 × 1"的经典套路。

**例 3** 计算 $\displaystyle\int x\arctan x\,\mathrm{d}x$。

**解**：取 $u = \arctan x$，$\mathrm{d}v = x\,\mathrm{d}x$，则 $\mathrm{d}u = \frac{\mathrm{d}x}{1+x^2}$，$v = \frac{x^2}{2}$：

$$
\begin{aligned}
\int x\arctan x\,\mathrm{d}x &= \frac{x^2}{2}\arctan x - \frac{1}{2}\int \frac{x^2}{1+x^2}\,\mathrm{d}x \\
&= \frac{x^2}{2}\arctan x - \frac{1}{2}\int\left(1 - \frac{1}{1+x^2}\right)\mathrm{d}x \\
&= \frac{x^2}{2}\arctan x - \frac{x}{2} + \frac{1}{2}\arctan x + C
\end{aligned}
$$

**例 4（循环型）** 计算 $\displaystyle\int e^x \sin x\,\mathrm{d}x$。

**解**：记 $I = \int e^x\sin x\,\mathrm{d}x$。取 $u = \sin x$，$\mathrm{d}v = e^x\mathrm{d}x$：

$$
I = e^x\sin x - \int e^x\cos x\,\mathrm{d}x
$$

对 $\int e^x\cos x\,\mathrm{d}x$ 再分部一次（$u = \cos x$，$\mathrm{d}v = e^x\mathrm{d}x$）：

$$
\int e^x\cos x\,\mathrm{d}x = e^x\cos x + \int e^x\sin x\,\mathrm{d}x = e^x\cos x + I
$$

代回原式：

$$
I = e^x\sin x - e^x\cos x - I \;\Longrightarrow\; 2I = e^x(\sin x - \cos x)
$$

$$
\int e^x\sin x\,\mathrm{d}x = \frac{e^x}{2}(\sin x - \cos x) + C
$$

> 出现"原积分 $I$ 再次出现"时，把它当作未知数解方程即可；同理 $\int e^x\cos x\,\mathrm{d}x = \frac{e^x}{2}(\sin x + \cos x) + C$。

## 六、方法选择速查

| 被积函数特征 | 首选方法 |
|------|------|
| 出现"某函数的导数"因子，如 $x e^{x^2}$、$\frac{1}{x\ln x}$ | 第一类换元法（凑微分） |
| 含 $\sqrt{a^2-x^2}$、$\sqrt{a^2+x^2}$、$\sqrt{x^2-a^2}$ | 第二类换元法：三角代换 |
| 含 $\sqrt[n]{ax+b}$ | 第二类换元法：根式代换 |
| 分母中 $x$ 的次数远高于分子 | 第二类换元法：倒代换 $x = \frac{1}{t}$ |
| 乘积形式：多项式 ×（指数/三角/对数/反三角） | 分部积分法（反对幂指三） |
| 有理分式 | 先拆分部分分式，再逐项积分 |
| 三角函数的偶次幂 | 用降幂公式 $\sin^2 x = \frac{1-\cos 2x}{2}$ 降次 |

**一般顺序**：能凑微分就先凑 → 不行再看根式换元 → 再考虑分部积分 → 三角有理式先做万能代换 $t = \tan\frac{x}{2}$。

## 七、常见易错点

1. **漏写任意常数 $C$** ⚠️
   不定积分表示的是**一族**原函数，$C$ 不可省。若题目给出初始条件求特解，再代入确定 $C$。

2. **换元后忘记回代**
   第二类换元法的结果必须换回自变量 $x$。用 $t$ 表示的答案在不定积分中不算完成。

3. **忽略 $\varphi'(t) \neq 0$ 与单调性**
   第二类换元要求 $x = \varphi(t)$ 单调可导，否则反函数不存在、无法回代。三角代换中限定 $t$ 的范围（如 $x = a\sin t$ 取 $t \in \left[-\frac{\pi}{2},\frac{\pi}{2}\right]$）正是为了满足这一点。

4. **三角代换回代时符号出错**
   开根号要保证非负：$\sqrt{a^2-x^2} = a\cos t$ 成立依赖 $t$ 在 $\left[-\frac{\pi}{2},\frac{\pi}{2}\right]$ 上 $\cos t \geq 0$。做 $\sqrt{x^2-a^2}$ 类题目前先讨论 $x > a$ 或 $x < -a$。

5. **分部积分选错 $u$**
   取 $u$ 的顺序是"反对幂指三"，取反了会越积越复杂。发现 $\int v\,\mathrm{d}u$ 比原积分更难看时，立刻交换 $u$ 与 $\mathrm{d}v$ 重来。

6. **验算习惯**
   求出结果后对答案求导，看是否等于被积函数——这是最可靠的检查手段：$\left(\frac{x^2}{2}\arctan x - \frac{x}{2} + \frac{1}{2}\arctan x\right)' = x\arctan x$。

## 八、总结

- **两条主线**：换元法（改变积分变量）与分部积分法（拆分乘积），几乎所有不定积分技巧都是这两者的组合与变形。
- **第一类换元**靠"凑"，把 $\varphi'(x)\mathrm{d}x$ 凑成 $\mathrm{d}\varphi(x)$，无需回代；
- **第二类换元**靠"换"，令 $x = \varphi(t)$ 去掉根号，**必须回代**，回代可用辅助直角三角形；
- **分部积分**口诀"反对幂指三"定 $u$，循环型题目把原积分当未知数解方程；
- 最后别忘了 $C$，并用**求导验算**收尾。
