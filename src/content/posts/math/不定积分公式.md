## 基本积分公式

| 公式 | 说明 |
|------|------|
| $\displaystyle\int 0\,dx = C$ | 常数积分 |
| $\displaystyle\int x^u dx = \frac{x^{u+1}}{u+1} + C\;(u \neq -1)$ | 幂函数积分 |
| $\displaystyle\int \frac{1}{x} dx = \ln\|x\| + C$ | 倒数积分 |
| $\displaystyle\int a^x dx = \frac{a^x}{\ln a} + C$ | 指数函数积分 |
| $\displaystyle\int e^x dx = e^x + C$ | 自然指数积分 |
| $\displaystyle\int \sin x\,dx = -\cos x + C$ | 正弦积分 |
| $\displaystyle\int \cos x\,dx = \sin x + C$ | 余弦积分 |
| $\displaystyle\int \frac{1}{\cos^2 x}dx = \tan x + C$ | 正割平方积分 |
| $\displaystyle\int \frac{1}{\sin^2 x}dx = -\cot x + C$ | 余割平方积分 |
| $\displaystyle\int \frac{1}{\sqrt{1-x^2}}dx = \arcsin x + C$ | 反正弦积分 |
| $\displaystyle\int \frac{1}{1+x^2}dx = \arctan x + C$ | 反正切积分 |
| $\displaystyle\int \frac{1}{a^2-x^2}dx = \frac{1}{2a}\ln\left\|\frac{a+x}{a-x}\right\| + C$ | 分式积分 |
| $\displaystyle\int \sec x\,dx = \ln\|\sec x + \tan x\| + C$ | 正割积分 |
| $\displaystyle\int \frac{1}{a^2+x^2}dx = \frac{1}{a}\arctan\frac{x}{a} + C$ | 分式反正切 |
| $\displaystyle\int \frac{1}{\sqrt{a^2-x^2}}dx = \arcsin\frac{x}{a} + C$ | 带参数反正弦 |
| $\displaystyle\int \sec^2 x\,dx = \tan x + C$ | 正割平方 |
| $\displaystyle\int \operatorname{sh} x\,dx = \operatorname{ch} x + C$ | 双曲正弦积分 |
| $\displaystyle\int \operatorname{ch} x\,dx = \operatorname{sh} x + C$ | 双曲余弦积分 |
| $\displaystyle\int \operatorname{th} x\,dx = \ln(\operatorname{ch} x) + C$ | 双曲正切积分 |

## 核心概念

**不定积分**是求导的逆运算：若 $F'(x)=f(x)$，则 $\displaystyle\int f(x)dx = F(x) + C$。

### 第一类换元法（凑微分）

利用 $f'(x)dx = df(x)$ 拼凑，把 $f(x)$ 看作整体求积分。

### 分部积分法

$$\int u\,dv = uv - \int v\,du$$

适用于：三角函数 × $x$、指数/对数函数 × $x$ 等乘积形式。
